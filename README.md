# Weaver ——《复调》（Polyphony）

> 2D 像素风叙事探索游戏（Godot 4.x，PC／Steam）。主题：**理解，不意味着成为彼此。**
> 五个区域、50 种特质、一条主旋律贯穿五关、终局五变奏合流。

## 当前状态

✅ **鸣响墟垂直切片可玩**（横版侧视·有重力，约 10–15 分钟）：
听声收集 ×10（四种获取挑战：共鸣探测显形／静默等待／回声机音序应答／属性配平）、
三声部分工战斗（爆／散／安抚）＋ 声音应答机制、失调调声、渐盲 Boss、手柄支持。

## 运行

- 双击 `02-Game/运行游戏.bat`（需本机装有 Godot 4.4，引擎本体在 `03-Tools/`，不入库）
- 或用 Godot 4.4+ 打开 `02-Game/project.godot`

## 关键设计速览

- 核心循环：**走 → 听 → 捡 → 装 → 打 → 调 → 融**
- 主题句机制化："你发出的每一个声音，都会有东西应答"＝开火会惊动失调体
- 失调＝正在失去声部（0–100，无死亡设计；满格失声退回回响点）
- 敌人＝失调体：净化与击碎皆可——僵直窗口内引导净化，或击碎
- 五音调式：商 → 角 → 羽 → 徵 → 宫（曲终归宫）
