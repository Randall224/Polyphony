## 一、游戏名称与主题

**《复调》**（英文：Polyphony）

- **主题**：**理解，不意味着成为彼此。**
- **名称寓意（已随剧情定稿）**：真正的复调，不是让所有声音唱同一个音，而是让不同的声音仍然能够共同存在——重织结局是这个名字的玩法化实现。
- **玩家玩完应该带走的**：
  - "如果我是当年的他，我真的会做得不一样吗？"
  - "我想被别人理解的时候，是不是也会下意识要求别人变得和我一样？"

## 三、世界观与主线节奏

### 3.1 背景故事（楔子：玩家开局不会看到的部分）

**五域简史**——很久以前，五个区域并不只是五个地方，而是五种完全不同的存在方式：**声音——表达；结构——思考；沉默——保留；节律——感受；边界——停止**。它们各自生长、互不相通，世界因差异而存在。

**织语者**——后来出现了一个人：唯一能在五域之间行走的人。他听得懂五种语言，能把一种语言转换成另一种——人们称他为**织语者**。但他慢慢发现了一件非常痛苦的事情：他可以理解所有人，却没有任何人能够理解他。他成了所有区域之间的桥，而桥本身没有归属。于是他有了一个看起来无比合理的想法：**如果所有语言最终都能变成一种语言，所有人就能真正理解彼此。** 这不是征服，不是邪恶，甚至不是傲慢——这是一个孤独的人得出的答案。

**融合与原初**——织语者完成了融合。五种语言第一次完全重合：没有冲突、没有误解、没有隔阂，一切都"正确"。然后，世界突然变得安静——不是声音消失，而是**不再存在"不同的声音"**。这就是"原初"：没有恶意，甚至没有意识，只是一种让所有差异趋向相同的倾向。它最可怕的地方不是毁灭，而是——**它认为一切都已经足够好了。** 原初在游戏中的全部呈现都必须遵循这一点：它不是敌人，是一种让一切越来越"正确"的趋势。

**犹豫与打碎**——织语者终于明白：自己最大的错误不是融合五种语言，而是相信**"被理解"必须以"变得相同"为代价**。但为时已晚——只要他继续保持完整，原初就会重新出现，因为**原初就是织语者自己的"统一意志"**。于是他把自己打碎，把五种核心分别还给五个区域。
**打碎之前，他犹豫过。** 他问了一句话："**如果我不再完整，你们会不会记得我？**"五个区域没有回答。于是他动手。——50 种特质因此不只是能力：**它们是五个区域记得他的方式。**

**散落之后**——原初的倾向散进特质，区域仍在缓慢死寂——只是极慢。五个区域在等待一个曾经离开的东西回来。**而那个东西，就是玩家。**

### 3.2 玩家与开场

黑屏，听见很轻的一次呼吸。像素画面出现时，玩家已经在走路——没有任务、没有介绍、没有地图，只有一条存在很久的**痕迹**。触碰第一个特质，浮现一行字：

> **"你已经来过这里。"**

**全游戏的悬念不是"我是谁"，而是：为什么这里在等我？为什么这些东西认识我？**（玩家＝织语者的回归，此反转已确认。）

**玩法动词递进**：**接收（听）→ 修复（建）→ 克制（等／潜）→ 主导（奏／引领）→ 放下（认／选）**——从"世界对你做什么"，到"你对世界做什么"，最后到"不再做什么"。

**台词呼应链**：五句关底台词首尾相衔，每一句都在为下一句蓄力。

**叙事原则（评审采纳）**：①每关只保留一句负责记忆的核心台词，其余文本都为它服务，避免金句堆叠；②身份揭示靠证据链让玩家自己推断，正式确认拖到望乡台；③"五域用五十种特质回答了"这层意思在前四关不断被感受，但直到望乡台才说破；④环境叙事密度（参照空洞骑士）：每关 3–4 块可读碑文点缀＋让几何本身讲故事。

**命名层级**：核心特质＝"原X"、边缘特质＝"末X"、隐藏特质＝谜面、普通特质＝具体的物与瞬间——名字本身就是层级语言。

### 3.5 一句话故事与五关连读

**一句话故事**：

> 一个曾经因为太渴望被理解、而试图让所有声音变成同一个声音的人，在失去自己之后重新走回原地，并第一次真正学会：理解另一个存在，并不需要让它变成自己。而最后的选择不是"要不要拯救这个世界"，而是"我已经知道自己为什么犯过那个错——现在，我还会再犯一次吗？"

**五关连读**：

> 你沿着一条存在了很久的痕迹醒来，在声音的废墟里捡起第一块碎片——这个世界认识你。在塔里，你发现自己的行动顺序和塔当年的建造顺序一模一样，还给过去的自己留了一句警告：你已经来过这里，而且你曾经知道结局。在渊底，你听到了自己当年没说出口的话——他也许不是畏罪，是真的别无选择。在海心，你奏回了失去的律，却在合鸣完成的瞬间看清：你一路做的，正是他当年做的事——让不同的东西趋向同一个东西。最后在望乡台，全部记忆归位：你不是拾荒者，你是织语者本人；五域从没请你拯救它们，它们只是把你的五个部分一点点叫了回来——它们当时没有回答你的问题，但它们用五十种特质回答了。现在，完整如新的你站在自己当初做选择的地方：归还、重织、离开——或者，如果你曾在中途放下寻找、遇见过那个不属于任何语言的音——跟它走。

### 3.6 元结构：每一周目就是轮回的一次

游戏不计数、不明说，但在结构上确立：**玩家的每一次游玩，都是织语者的一次归来。**

- 每周目的属性随机与游荡分布＝"每一次回来，世界都不完全一样"；
- 轮回囚徒的主菜单重置＝字面意义上下一次轮回的开场；
- 玩家自己的重玩行为，就是织语者的重复——**元结构本身即主题（Da Capo）**；
- **循环被打破的周目**（见证者、《闰音》之后）不再被叙事收编——它们是走出轮子的"如果"。

## 四、游戏系统

### 核心循环

**走 → 听 → 捡 → 装 → 打 → 调 → 融**。沿痕迹前行（走），共鸣探测定位（听），触碰收集（捡），声部槽配装（装），与失调体交战（打），跟随调式 BGM 排解失调（调），在特质库中把特质融合成声部（融）。宏观定位：叙事驱动的探索动作游戏，构筑与轻音游为系统层。

### 发音：攻击与交互的母动词

**攻击＝让特质发音。** 每个装填在声部槽的特质绑定一个发音，发动时发出对应属性的音波——释放型＝攻击波，吸收型＝牵引／护盾，快＝连发，慢＝重击，坚韧＝格挡。**配装即曲风，战斗即演奏**。母动词是**发声**，但它的对立面**静默**同样是系统的一部分（空音渊整关建立在"不发声"上）。准确的表述是：**全游戏围绕声音与沉默的关系展开**。

**特质呈现**：每个特质＝一个发音＋一个专属图标＋一句介绍文本。被动效果极简；没有纯数值特质。

### 特质三层与剧情嵌合

50 种特质分三层：**能力**（实际可用）、**关系**（协同／冲突／中和／替代——构筑系统）、**记忆**（剧情碎片）。

**特质—剧情嵌合原则**：剧情的推进权交给特质，而不是交给收集进度——
- **剧情主驱＝5 个核心特质**：每个核心特质的获得都是一次**世界状态改变**，并各自浮出该关的核心问题；
- **剧情钥匙＝5 个隐藏特质＋每关 1–2 个指定特质**：主要揭示节拍绑定在具体特质上；
- **氛围回响＝25 个普通特质**：触碰时给一句不解释的"回响"——它们是"五域用五十种特质回答了"的质感本身；
- 计数只保留在后台，玩家看到的永远是**具体特质带来的具体变化**。触发链见 3.4。

**计数呈现原则**：前期不向玩家展示精确收集总数，直到望乡台选项阶梯浮现时，"50"的意义才第一次显形。

### 品质语义

- **高品质特质＝过去已经总结出的答案**：稳定、通用、低认知成本——是捷径；
- **低品质特质＝还没被理解透彻的东西**：效果狭窄，但拥有特殊的组合空间。
- **品质与层级正交**：在各层内部随机分布。层级决定"怎么获取"，品质决定"好不好用"。
- **品质的机制锚点**：品质＝同一层级内发音的**稳定性与组合宽度**的随机档位。品质体现"理解深度"，不是稀有度等级。

### 构筑原则

不设计成"收集越多→数值越高"，而是**收集越多→选择越多→冲突越多**。

### 失调（原"混沌值"改名）与调声

> 术语约定：**调声**＝玩家在换气点排解自身失调的动作；僵直的失调体在窗口结束后**自动净化**（无需玩家输入）。

- 失败分类（同向叠加）：释放＋释放＝**过载**；快＋快＝**失控**；结构过强＋规则过强＝**僵化**。
- **失调的三个来源**：①装填冲突——同向属性成对计入失调基底；②受击；③过载使用——连续重复使用同一发音。
- 中和：释放↔吸收（平衡）、快＋慢（缓冲）、脆弱＋坚韧（承载）。
- **调声**：跟随当前关卡调式 BGM 的节奏输入来排失调——**音乐系统是操作对象**。调声是内心动作（听之以心），**不出声**——在空音渊的寂静中同样可用。
- **调声的限制**：必须站立静止，且只在 BGM 乐句的换气点可输入（每乐句至多一次）；战斗中无法调声。"找地方调声"因此是探索节奏的一部分。
- 失调过高：操作判定劣化（**劣化＝容错窗口变窄，不是不可完成**）；声部逐个**失声**；已融合特质**暂时脱落**（直接装填的特质落回世界原处可再取；融合声部**解体**为成分特质回库）。

### 声部槽与特质库

特质装填上限 3～4 槽。build 同时决定战斗能力与解谜解法——多解设计。

**容量双层模型**：
- **上限层（进度）**：开局 3 格；断章塔核心特质完成后升至 4 格，**永久封顶**。槽位＝玩家能同时容纳的差异的数量——上限 4 意味着一路上永远装不下五个声部，直到重织的一刻，第五个声部才第一次属于你。
- **可用层（失调）**：实际可用槽位随失调动态收缩——失调越高，声部一个个"失声"。**轮回路线的玩家一路不调声，走到终局时手里真的只剩一个声部**——假重织结局"你的复调其实只有一个声音"在 HUD 上提前成真。
- 失调的惩罚因此是一条连续曲线：**失调，就是正在失去声部。**

**特质库**：未装填的特质收入随身的特质库。50 种全部存于库中，声部槽只是它们"上场"的方式。闰音不占声部槽。

**库界面**：Tab 打开特质库面板——列出已收集特质的三属性（能量／结构／节奏），**W/S 选特质、A/D 选槽位（▶标记）、E 装入、Q 卸下**。切片已实现基础版；融合操作在断章塔解锁后加入同一面板。

### 融合

特质可直接装填（基础效果）；**融合＝把 2～3 个特质合成一个"声部"**：占 1 格、能力显著增强，并可能解锁专属交互。融合是构筑的进阶动作，也是配方挑战（共振腔、区域门）的解题工具。

### 属性与搭配系统

**三属性九值**——属性的取值直接决定它的发音与效果：

| 属性 | 值 | 发音／效果 |
| :--- | :--- | :--- |
| 能量倾向 | 释放 | 攻击波——对外输出，主削韧手段 |
| | 吸收 | 牵引＋护盾——拉近敌人、抵消音波 |
| | 中性 | 无对外效果，但是**万能中和剂**：与任何属性相邻都不构成冲突，且强化相邻特质发音 +20%（共鸣） |
| 结构强度 | 坚韧 | 格挡＋反击硬直 |
| | 中等 | 标准效果 |
| | 脆弱 | 效果强于中等，但受击时该特质进入 5 秒失声 |
| 节奏频率 | 快 | 连发——短间隔多次，单次削韧低 |
| | 中 | 标准节奏 |
| | 慢 | 重击——长前摇、高削韧 |

**搭配规则**——声部槽最多 4 格，槽内特质两两之间发生"关系"：

- **失调基底（全局）**：所有已装特质中，每对**同向属性**＋8（含跨槽配对）——这是构筑的代价。
- **中和（相邻触发）**：释放‖吸收、快‖慢、脆弱‖坚韧 相邻时，该对**豁免基底**，并激活中和效应——释放‖吸收＝**平衡**（发音命中时自身失调 −2）；快‖慢＝**缓冲**（全部判定窗口 +20%）；脆弱‖坚韧＝**承载**（脆弱特质不再因受击失声）。
- **协同（相邻触发）**：同名值相邻（如快‖快）→ 效果 +30%，但该对照常计入基底——**强度换稳定**。
- **三连同向**：三个同值相邻 → 基底 +8×2，且发音有概率自增失调——最激进也最危险。
- **替代**：同名特质不能同时装填——第二颗是融合材料或备份。

**融合的属性合成**：融合产物的三属性**逐维从参与者对应维度中选择其一**（玩家决策）。产物发音＝参与者发音的复合形态。跨区域特质融合可产出"跨域声部"，是区域门与共振类挑战的钥匙。

**构筑原型示例**（build 差异体现在攻击节奏、空间位置与决策，不是 DPS 数字）：

| 原型 | 组合特征 | 战斗风格 | 失调风险 |
| :--- | :--- | :--- | :--- |
| 连发型 | 快＋快＋释放（协同） | 高频压制、贴脸输出 | 高（同向基底） |
| 反打型 | 吸收‖坚韧‖慢（中和） | 格挡反击、后发制人 | 低 |
| 爆发型 | 释放＋慢＋坚韧 | 一击重削、游走拉距离 | 中 |
| 平衡型 | 释放‖吸收‖快‖慢（全中和） | 万金油、探索友好 | 基底近零，但无协同加成 |

### 战斗：敌人＝失调体

**失调体的叙事身份**：原初倾向的凝块——织语者"统一意志"的残渣。**净化＝自动回归**（僵直结束时残渣归位、声部重谐），**击碎＝销毁残渣**。销毁的是残渣，不是记忆。**原初不是和谐，是最深的失调：只剩一个声部的"协调"。** 因此三类敌人恰是失调的三种面目——过载、失控、僵化，其中僵化型离原初最近。

| 类型 | 行为 | 伤害形态 | 克制要点 |
| :--- | :--- | :--- | :--- |
| 过载型 | 蓄力 1.2s → 近距爆发音波 → 硬直 1.5s | 近距爆发音波 | 吸收型发音可吞掉音波无伤；慢速发音可在蓄力期打断 |
| 失控型 | 每 0.8s 随机变向高速游走＋偶发冲刺；加发 3 向音弹 | 冲撞＋音弹（可闪避） | 坚韧型格挡冲撞并令其硬直；预判走位 |
| 僵化型 | 固定路线巡逻、每 4 拍固定挥击一次；带甲 | 挥击＋压迫场 | 只打面朝方向——绕背；可引至压板／当垫脚 |

战斗循环：属性克制削韧 → 韧性清空 → **僵直 3 秒**：什么都不做则自动净化（慢而有益）；继续攻击则击碎（快而无残留）。**僵直期的处理留下隐性记录（击碎率），喂给结局判定**——两条路都好玩，都通向任何结局。

**打击感三件套（参照空洞骑士）**：①命中瞬间 40–60ms 全局 hit-stop（time_scale 0.05）；②击碎／净化时 1–2px 屏幕微震＋声纹粒子迸发；③玩家受击有击退感与 0.8s 无敌帧。战斗"正确"还必须"有重量"。

**遭遇密度**：失调体不是刷出来的怪，而是**路障**——它们聚在特质富集处与通道隘口。密度由玩家的收集路线决定，大部分战斗可以绕开——**战斗是收集的代价，不是巡逻的义务**。

### 共鸣探测（听音寻踪）

站定静默倾听，未收集特质发出微弱音，声像定位＋画面涟漪指示方向。挂接"心斋三重听"进阶：一重近距可闻 → 二重隔墙可闻 → 三重跨区域感知游荡去向。**不是"按一下出箭头"的雷达——呈现从模糊到精确，随三重听成长。**

### 成长与失败

**失败状态——无死亡设计**：不存在死亡。失调满格时玩家短暂"失声"：世界对玩家静音、操作迟滞，退回最近的**回响点**。特质永不丢失，进度不清空。

**成长曲线**：
- 声部槽上限：开局 3 格；断章塔核心特质完成后升至 4 格（封顶）；
- 心斋三重听：开局一重；断章塔核心完成后升二重；无律海核心完成后升三重；
- 失调上限：维持常量。

**系统解锁节奏**：

| 节点 | 解锁 |
| :--- | :--- |
| 开局 | 移动／触碰／声部槽 3 格／一重听 |
| 鸣响墟中段 | 共鸣探测／调声 |
| 断章塔中段 | 融合 |

| 无律海核心后 | 三重听／望乡台界墙融化 |

**教学策略**：零 UI 原则不变，不设教程关——基础操作由鸣响墟的普通特质承担教学（**普通层＝教学层**）；融合推迟到断章塔引入。

**节拍辅助（无障碍）**：辅助开关放宽判定窗口／提供自动踩拍；辅助模式可通全部结局——辅助不歧视。

**手柄支持**：Xbox 布局全键位＋受击/击碎振动，已在切片实装。

### 象罔得珠（《闰音》专用获取机制）

出自《庄子·天地》：知、离朱、喫诟索之不得，乃使象罔，象罔得之——最会找的人找不到，无心的人才遇得到。**全游戏只有《闰音》（第 51 种特质）使用此机制**。

**三个失效**：知之失效（探测探不到）／离朱之失效（无视觉高亮，只是一段"调式之外的音"）／喫诟之失效（追逐行为使它隐没）。

**显现条件**：①当前区域可收集特质已清空；②步行漫游或静立倾听持续一段时间；③近期（60–90 秒，仅内部参数）未使用共鸣探测。**发现时机：不设门控。** 实践中最常被遇见处＝望乡台纯白边缘。

**它的性质**：无三属性、不能融合、不占声部槽；不计入 50 种门槛；错过不惩罚；收下后名字才浮现：《闰音》。获得时展示专属介绍文本。

**交付方式**：象罔得珠只负责让相遇发生——持有后望乡台浮现第四选项，是否走这条路仍由玩家选。

**前期铺垫**："停止寻找，事物才出现"在揭晓前已被教学两次——鸣响墟的止语、空音渊的静默显现；《闰音》是这两课的终考。

### 游荡与随机

**总原则：叙事固定，属性随机；结构固定，分布游荡。**

- **游荡规则**：死寂推出、活力吸引——玩家压制失调会吸引特质。**追踪成本红线**：三重听满级后追踪成本趋近于零，游荡只改变路线与偶遇，绝不制造跑腿清单。
- **总量守恒**：50 种各有唯一实例，全收集永远可能。
- **望乡台例外**：普通层不参与游荡与随机。
- **主题暗线**：普通特质游荡而核心固守——没有归属的东西在漂泊，和玩家一样。

**机制族（实现原则）**：25 个定制获取归并为 **6 个机制族**——音游节奏族、潜行族、指认族、战斗族、解谜族、仪式行走族；原序为纯叙事抉择。

> 断章塔重构记录：**"最后一块"与核心特质原序合一**——放入或不放入皆获得原序并进入第三关；差别只在未写的规则（不放入获得）。抉择不计入回答倾向。

### 兼容性总规则

> **一周目内，全收集与任何结局同时可达。任何两个特质的获取条件不得互斥。**

（逐项排查表见历史版本；结论：全部无冲突——僵直自动净化后，"击碎记录"仍可区分路线。）

## 九、实现规格（数值 · 行为 · 音频 · 技术）

### 9.1 失调数值（0–100）

> 数值属性：**关系已固定，参数为原型初值**。校准的验收标准是体验曲线。

| 项 | 数值 |
| :--- | :--- |
| 装填冲突基底 | 每对同向属性同时在场 +8（静态，装填变更时重算） |
| 受击 | 每次 +6 |
| 过载使用 | 同一发音连续第 4 次起，每次 +4 |
| 调声 | 每次 −12（限站立静止、乐句换气点、每乐句至多一次） |
| 自然衰减 | 仅基底 ≤8 时生效，−1/秒 |

阈值表：

| 失调 | 效果 |
| :--- | :--- |
| ≥40 | 第 4 槽失声（若已解锁） |
| ≥60 | 第 3 槽失声；全部判定窗口 −30% |
| ≥70 | 边缘特质可见（风险显形阈值） |
| ≥80 | 只剩 1 槽可用；已融合声部开始脱落（每 10 秒一个） |
| ＝100 | 彻底失声 → 退回最近回响点；失调重置为 **30** |

轮回判定："失调长期高位"＝全程 ≥70 的时间占比 ≥80%。

**压力曲线校准原则**：0–30 轻松探索；30–60 主动决定是否调声；60–80 明显危险但可完成；80–100 世界逐渐"少了声音"；满格失声＝戏剧性而非挫败。**失调的多重反馈**：声音（总线失真）、视觉（声部熄灭）、操作（判定窗口）、环境（声层减少）。

### 9.2 失调体行为模型

**通用框架**：韧性条。克制属性命中削韧 ×2、非克制 ×1、同向命中削韧 ×1 且自增失调 +3。韧性清空 → **僵直 3 秒（自动净化窗口）**→ 净化（化为安静光点，留场 30 秒并扩大共鸣探测范围）；僵直期内被攻击＝**击碎**（声纹粒子消散）。净化与击碎都计入**击碎记录**。

**声音应答（通用规则，"你发出的每一个声音，都会有东西应答"的机制化）**：任何发音都会被 250 内巡逻中的失调体听见并进入敌对（蓄力逼近）；受击的失调体同样惊动附近同伴。因此**开火是有代价的资源**：远距狙杀会把敌人引到你脸上，潜行绕过则要求闭嘴。安抚脉冲（中性声部）可让敌对中的失调体脱离敌对；对僵直中的失调体使用＝**引导净化**（与击碎相对的另一种了结）。

**三声部分工（声部槽属性决定行为，不是三个弹弓）**：放（release）＝攻击声部——快调＝同向三连爆、慢调＝重击慢弹、脆结构＝扇形三向散（每响自增失调）；收（absorb）＝**回声牵引**——把身前失调体拉向你（拉进近身距离或拉下平台）；静（neutral）＝**安抚脉冲**。坚韧结构附护盾。

| 型 | 韧性 | 行为 | 伤害形态 | 克制要点 |
| :--- | :--- | :--- | :--- | :--- |
| 过载型 | 30 | 蓄力 1.2s → 近距爆发音波（半径 2.5 格／120° 扇形）→ 硬直 1.5s；直线逼近 | 近距爆发音波 | 吸收型发音可吞掉音波无伤；慢速发音可在蓄力期打断 |
| 失控型 | 20 | 每 0.8s 随机变向高速游走＋偶发冲刺；加发 3 向音弹 | 冲撞＋音弹（可闪避） | 坚韧型格挡冲撞并令其硬直；预判走位 |
| 僵化型 | 50 | 固定路线巡逻、每 4 拍固定挥击一次；带甲（非弱点削韧减半） | 挥击＋压迫场 | 只打面朝方向——绕背；可引至压板／当垫脚 |

缩放：韧性 ×(1＋0.15×（区域序号−1）)。玩家伤害不随时间成长，成长只来自品质与融合。

**重生规则**：失调体不主动重生——净化或击碎后，该处只有在该区失调基底回升至阈值（≥40）时才会重新凝出新的凝块。

**打击感三件套**：hit-stop／微震／清晰无敌帧——已在切片实装（见第四节）。

### 9.3 回响点与成长校准

- 回响点：每关 4–5 个；形态＝一盏还亮着的灯，激活时响起该关调式的主音（空音渊的几乎听不见）。**参照空洞骑士的长椅**：激活时玩家驻足，环境声层收拢两拍再回落——"喘息"的叙事装置。
- 玩家伤害成长＝品质＋融合；敌人韧性每关 +15%。
- 失调上限恒定 100；僵直（自动净化）窗口恒定 3 秒。

### 9.4 音频实现 brief

**主旋律规格**：C 宫五声（C D E G A）；8 小节（2 小节乐句 ×4）；84 BPM；动机＝级进上行三音组＋一次四度跳进回落；**换气点＝每 2 小节乐句末**（调声输入点）。主旋律来源已定：**由 AI 依据背景与剧情创作**；垂直切片阶段使用脚本生成的占位音频（BPM 与换气点结构一致）。

**五关变奏规则**：

| 关 | 调式中心 | 速度 | 音色 | 变奏手法 |
| :--- | :--- | :--- | :--- | :--- |
| 鸣响墟 | D（商） | 72 BPM | 钟、石质打击、长混响 | 旋律碎片化——只出现动机前三个音 |
| 断章塔 | E（角） | 96 BPM | 木鱼、编钟、点状 | 旋律节拍化——骨架严格对齐拍点 |
| 空音渊 | A（羽） | 56 BPM | 低音单音、超长混响 | 只保留每句首尾音，中间全是间隔 |
| 无律海 | G（徵） | 84→118 BPM 浮动 | 水声打击、弦震 | 旋律语序打乱重排，偶发整体滑半音 |
| 望乡台 | C（宫） | 84 BPM | 弦＋钟齐鸣 | 五关版本以对位法同时进入，终曲全奏 |

**音效表**：收集＝该关调式单音（按收集序上行）／融合＝和弦／调声成功＝正拍主和弦／击碎＝碎裂噪声（低通渐闭）／失声＝全总线低通下沉／呼唤＝人声气声单音，渊的回应＝倒放混响／闰音＝C 宫五声之外的音（F♯／B♭）——全游戏唯一。

### 9.5 技术决策

- **引擎：Godot 4.x（GDScript），确认**。免费开源；2D 像素工作流成熟；AudioServer 实时总线效果（失声＝总线低通）。
- **像素规格**：基础分辨率 640×360，整数倍缩放；瓦片 16×16，主角 16×24；每关一套调色板，失调与失声＝饱和度与低通联动。
- **移动视角**：**横版侧视·有重力**（左右移动＋跳跃；跳距约 4 瓦、跳高约 4 瓦）。垂直段用平台攀爬表达；塔层／深渊等大落差段落乘坐升降（吊笼／声波电梯）。历史上曾试做俯视四方向版，因"现实感"（重力、落差、坠落）不足改回横版——见开发问题日志第 9／14 条。
- **存档**：回响点自动存档（特质收集、击碎记录、五答、区域状态、闰音持有）；无手动读档回滚；结局印记（轮回重置不清印记）。
- **手柄**：Xbox 布局全键位＋振动反馈，已实装。
- **Steam 查重（已在线预检）**：未发现同名在售作品；注意 Polyphony Digital 为索尼工作室名。上架前后台终验。

### 9.6 完整性自检（开发就绪度）

玩家旅程／50 特质／战斗／音频／技术／手柄——全部有定义。**有意留给生产阶段的**：关卡几何布局与美术资产、场景文本润色、结局影像分镜、本地化、成就设计。

## 十、设计红线与验证路线（评审采纳）

### 设计红线

| 红线 | 解释 |
| :--- | :--- |
| 玩家永远有办法继续 | 无永久特质损失；失败是失声与回响点 |
| 五关可以不同，底层语法一致 | 共享特质、音乐、失调、构筑与世界反馈 |
| 不靠数值刷成长 | 成长来自理解、选择与融合 |
| 任何结局都不依赖不可感知的惩罚 | 行为记录只产生叙事回响 |
| 全收集理论上始终可达 | 随机是分布，不是永久互斥 |
| 不为内容量增加系统 | 一律复用 6 个机制族 |
| 剧情尽量由玩法证明 | 少解释，多让玩家亲自得出结论 |
| 每关有自己的记忆点 | 但不脱离"复调"底层主题 |
| 平行哲学体系只作灵感层 | 五行／五感／五德等不进入玩家需理解的规则 |

### 参照系（空洞骑士）

打击感三件套／长椅仪式／碑文密度／区域旋律动机。市场佐证：护符式构筑＋高概念氛围叙事＋少数高浓度 Boss 已被验证。**不照搬**：死亡代价与魂资源循环、大型地图系统、手绘风格。

### 体验目标曲线

"这里为什么认识我？"→"原来这个地方在回应我的行动。"→"原来我可以不回应。"→"原来我也可以让它跟着我的节奏走。"→"等等——我是不是正在变成过去的那个人？"→"我已经知道他为什么这么做了。"→"现在轮到我决定：是否还要让世界和我一样。"

### 验证路线（P0）

| 步骤 | 内容 | 验证问题 |
| :--- | :--- | :--- |
| 1 | 鸣响墟 10–15 分钟垂直切片（✅ 已实装，横版重力版待实测） | 听声战斗手感、跳跃与平台节奏、调声节奏、渐盲可玩性 |
| 2 | 空音渊 10 分钟切片 | "不发声／等待"是否好玩 |
